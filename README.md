# Примерка Колёс — промосайт

Статический сайт сервиса ИИ-примерки автомобильных дисков. Репозиторий содержит
главный лендинг и страницу с готовым партнёрским виджетом; production публикуется
через GitHub Pages.

## Быстрый старт

Сборка и установка зависимостей не требуются:

```bash
python3 -m http.server 8000
```

После запуска откройте:

- <http://localhost:8000/> — главный лендинг;
- <http://localhost:8000/partners.html> — страница для партнёров.

## Документация

- [`AGENTS.md`](AGENTS.md) — структура репозитория, правила разработки и чек-лист;
- [`PROJECT_NOTES.md`](PROJECT_NOTES.md) — актуальные интеграции, архитектура и
  журнал важных изменений.

Основной стек: чистые HTML, CSS и JavaScript без сборщика и внешних библиотек.
